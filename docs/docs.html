What is Smith?

Agent Smith is a co-worker for the app-store part of your app. Your coding agent (Claude, Cursor, Codex…) writes the code. Smith does everything Apple and Google make you do afterward: builds, signing, screenshots, listings, in-app purchases, review, and rejections.

You never learn App Store Connect. You just tell your agent what you want — "put this on TestFlight", "submit version 1.2" — and the agent hands the work to Smith.

Non-technical? That's fine. The app has a guided, step-by-step connect flow that does everything below for you with buttons instead of a terminal.

Connect your agent (5 minutes)

Smith speaks MCP (Model Context Protocol) — the standard way agents connect to outside tools. You connect once; after that your agent can see and use Smith in every conversation.

The universal way, which works with 20+ agents:

npx add-mcp https://api.agentsmith.app/mcp

Or pick your agent:

Claude Code

Open your terminal in any project and run:

claude mcp add --transport http smith https://api.agentsmith.app/mcp

Then start Claude Code and type "list my apps with smith" to confirm it's connected.

Claude Desktop & claude.ai
  1. Open Settings → Connectors.
  2. Click Add custom connector.
  3. Name it Smith and paste https://api.agentsmith.app/mcp.
  4. Click Add, then approve the connection when asked.
Cursor

Create (or open) the file .cursor/mcp.json in your project and add:

{
  "mcpServers": {
    "smith": { "url": "https://api.agentsmith.app/mcp" }
  }
}

Restart Cursor. Smith appears under Settings → MCP.

Codex (OpenAI)

Add this to ~/.codex/config.toml:

[mcp_servers.smith]
url = "https://api.agentsmith.app/mcp"
VS Code + Copilot Chat

Run this in a terminal:

code --add-mcp '{"name":"smith","url":"https://api.agentsmith.app/mcp"}'

Or add the same server in Settings → MCP Servers.

Something else (Replit, Cline, Windsurf, …)

Any MCP-capable agent works. Look for "MCP servers" in its settings and paste https://api.agentsmith.app/mcp, or use the universal command at the top of this section.

Then connect your accounts

  1. App Store Connect — sign in once in the Smith app; this unlocks your 500 free credits. (No Apple account yet? Smith walks you through creating one — $99/yr from Apple.)
  2. Google Play (optional) — connect your Play Console the same way ($25 one-time from Google).
  3. GitHub (optional) — needed only for web→mobile conversion and builds from source.

Ship your first app

Once connected, shipping is a conversation. A typical first run:

  1. Say what you want. In your agent, type: "Use Smith to ship this app to TestFlight."
  2. Smith builds and uploads. It clones your repo, builds, signs, and uploads. First time usually takes ~15 minutes.
  3. Check status anytime. Ask "what's the status of my build?" — Smith answers with the live state from Apple.
  4. Go to the store. Say "submit it for review". Smith creates the version, attaches the build, fills the metadata, and submits.
  5. If Apple rejects it — say "handle the rejection". Smith reads Apple's feedback, explains it in plain English, fixes what it can, and resubmits.

Web app → mobile app

Built your app on Lovable, Emergent, Bolt, Replit, or v0? Smith turns it into a real iOS and Android app.

  1. Connect GitHub. Your builder already pushes your code to a GitHub repo — connect it to Smith.
  2. Smith analyzes. It detects your framework and scans for the things Apple and Google reject: web checkout (must become in-app purchases), missing account deletion, missing privacy policy, and "it's just a website" risk.
  3. Smith refactors. It wraps your app in a native shell, adds the iOS and Android projects, and hands your coding agent a fix list for anything that needs real code changes.
  4. Ship both stores. Icons, splash screens, signed builds — TestFlight and Play Console.
One prompt to start: "Take github.com/me/my-app and get it ready for the App Store and Google Play."

Prompts that work

Paste any of these into your agent (or your no-code tool's chat) once Smith is connected:

• "Ship the current branch to TestFlight and tell me when it's processed."

• "Draft the App Store listing for 1.2 — name, subtitle, keywords, and what's new."

• "We got rejected. Read the resolution center, explain why, and fix it."

• "Convert my Lovable app at github.com/me/app into an iOS and Android app."

• "Check my app for anything Apple or Google would reject before I submit."

• "Set up a $4.99/month subscription called Pro in all territories."

Troubleshooting

My agent doesn't see Smith

Restart the agent after adding the server — most only load MCP connections on startup. Then ask it to "list smith's tools".

"Missing App Store Connect credentials"

You haven't connected your Apple account yet. Open the Smith app and finish the App Store Connect step, or set your API key if you're self-hosting.

The build failed

Ask your agent: "show me smith's build error and fix it." That's the whole workflow — the agent reads the log, changes the code, and re-runs the build.

Anything else

Email support@agentsmith.app — Pro gets priority.
